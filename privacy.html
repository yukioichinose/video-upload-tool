プライバシーポリシー

Video Upload Tool（以下「本ツール」）は、運営者が自分のために使う個人用のツールです。本ツールが Google のデータをどう扱うかを説明します。

使う Google のデータと目的

  • YouTube Data API（権限：youtube.force-ssl）：運営者のチャンネルに動画をアップロードし、タイトル・説明・サムネイル・公開日時を設定します。運営者の動画の状態の確認、公開設定の変更、運営者のチャンネルの再生リストの作成と動画の追加にも使います。
  • Gmail API（権限：gmail.send）：運営者自身あてに作業の通知メールを送るためだけに使います。メールを読むことはありません。

保存と共有

  • 認証の情報（トークン）は、運営者のパソコンの中にだけ保存します。
  • Google から受け取ったデータを売ったり、広告に使ったりしません。運営者自身の作業に必要な場合を除き、第三者に渡しません。
  • Google から受け取ったデータで、AI のモデルを学習させることはありません。

アクセスの取り消し

Google アカウントの「サードパーティのアプリとサービス」から、いつでも本ツールのアクセスを取り消せます。取り消すと、本ツールはアカウントのデータを使えなくなります。

Google と YouTube のポリシー

  • 本ツールが Google API から受け取った情報の利用と、ほかのアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • 本ツールは YouTube API サービスを使っています。本ツールを使う人はYouTube 利用規約に従うものとします。Google のプライバシーポリシーは https://policies.google.com/privacy です。

Privacy Policy (English)

Video Upload Tool ("the tool") is a personal tool used only by its operator.

  • YouTube Data API (scope youtube.force-ssl): to upload videos to the operator's own channel, set their titles, descriptions, thumbnails and publish times, check the status of the operator's videos, change their privacy settings, and create playlists on the operator's channel and add videos to them.
  • Gmail API (scope gmail.send): only to send status emails to the operator. The tool does not read any email.
  • Tokens are stored only on the operator's computer. Data received from Google is not sold or used for advertising, is not shared with third parties except where needed for the operator's own use of the tool, and is not used to train AI models.
  • Access can be revoked at any time at https://myaccount.google.com/connections.
  • Video Upload Tool's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • The tool uses YouTube API Services. Users of the tool agree to the YouTube Terms of Service. Google Privacy Policy: https://policies.google.com/privacy
